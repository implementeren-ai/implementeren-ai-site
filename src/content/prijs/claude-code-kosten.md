De Claude Code kosten voor een bedrijf hangen af van één keuze: betaal je per ontwikkelaar een vaste seat, of betaal je per token wat er verbruikt wordt? Een token is een klein stukje tekst of code, vaak korter dan een woord. Claude Code koop je niet los. Volgens [de productpagina van Claude Code](https://claude.com/product/claude-code) zit het in de betaalde Claude-plannen, of je betaalt per token met een account in de Claude Console.

Hieronder staan alle routes naast elkaar, met een rekenvoorbeeld voor 5 ontwikkelaars. Alles is op 2 november 2026 gecontroleerd bij de bronnen onderaan. Wat Claude Code is, lees je in [Claude Code voor bedrijven](/gids/claude-code-voor-bedrijven).

## Wat kost Claude Code per ontwikkelaar?

Tabel: Wat Claude Code per ontwikkelaar per maand kost, per route, stand 2 november 2026.

| Route | Prijs per ontwikkelaar per maand (USD, excl. belasting) | Hoeveel gebruik | Voorwaarden | Past bij |
|---|---|---|---|---|
| Pro | $20, of $17 bij jaarbetaling | basis, gedeeld met chat | consument | één persoon die het probeert |
| Max | $100, alleen maandelijks | 5 keer Pro, per 5 uur en per week | consument | één zware gebruiker |
| Ultra (voorheen Max 20x) | $200, alleen maandelijks | 10 keer Pro per week, geen 5-uurslimiet voor een geverifieerd account | consument | één zeer zware gebruiker |
| Team, standaard seat | $25, of $20 bij jaarbetaling | 1,25 keer Pro per sessie | zakelijk | ontwikkelaar die af en toe werkt; 2 tot 150 seats |
| Team, premium seat | $125, of $100 bij jaarbetaling | 6,25 keer Pro per sessie | zakelijk | ontwikkelaar die er de hele dag in werkt |
| Enterprise | $20 per seat (jaarlijks, minimaal 20) plus al het verbruik tegen API-tarief | geen limiet per seat, je zet zelf limieten op de uitgaven | zakelijk | 20 of meer gebruikers |
| Claude Console (API) | per token; gemiddeld $150 tot $250 volgens Anthropic | geen seat, wel een limiet per workspace | zakelijk | wisselend gebruik, automatisering, kosten per persoon zien |

De bedragen komen van [de prijspagina van Claude](https://claude.com/pricing). Met de ECB-koers van 30 oktober 2026 (1 euro is 1,1172 dollar) kost een standaard Team-seat €17,90 bij jaarbetaling en €22,38 bij maandbetaling, een premium seat €89,51 of €111,89. Hoe dat op je factuur uitpakt, lees je bij [btw en wisselkoers bij Claude](/prijs).

Pro, Max en Ultra zijn abonnementen voor één persoon, onder de consumentenvoorwaarden van Anthropic. Het gratis plan heeft geen Claude Code. Op Pro, Max en Ultra deel je de limiet met de gewone Claude, staat in [het helpartikel over Claude Code op Pro, Max en Ultra](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-max-or-ultra-plan). Volgens [de kostendocumentatie van Claude Code](https://code.claude.com/docs/en/costs) deelt ook een Team-seat die ruimte met de chat en Cowork.

## Wat krijg je op Claude Team en Enterprise voor Claude Code?

Volgens [het helpartikel over Claude Code op Team en Enterprise](https://support.claude.com/en/articles/11845131-use-claude-code-with-your-team-or-enterprise-plan) zit Claude Code in elke Team-seat. Anthropic bevestigde dat ook bij de prijsverlaging van Team op 28 januari 2026.

Volgens [het helpartikel over het Team-plan](https://support.claude.com/en/articles/9266767-what-is-the-team-plan) krijgt een standaard seat per sessie 1,25 keer de ruimte van Pro en een premium seat 6,25 keer. Je mag ze in één team mengen. Ons advies: zet iedereen eerst op standaard en geef alleen wie de hele dag in Claude Code werkt een premium seat. De afweging tussen de plannen staat in [Claude Pro, Team of Enterprise](/prijs/pro-vs-team-vs-enterprise).

Zit een ontwikkelaar aan de limiet van de seat, dan kan een beheerder [usage credits voor Team aanzetten](https://support.claude.com/en/articles/12005970-manage-usage-credits-for-team-and-seat-based-enterprise-plans): gebruik tegen API-tarief, met een maandlimiet voor de organisatie en per lid. Lees vooraf [hoe de gebruikslimieten werken](/prijs/credits-en-limieten).

Claude Enterprise rekent anders. Volgens [het helpartikel over het Enterprise-plan](https://support.claude.com/en/articles/9797531-what-is-the-enterprise-plan) geeft de seat toegang tot Claude, Claude Code en Cowork, en betaal je al het gebruik apart tegen API-tarief. Er is geen limiet per seat, wel per organisatie en per gebruiker. Online koop je minimaal 20 seats, via sales minimaal 50.

Op Team, Enterprise en de API traint Anthropic geen modellen op code of prompts uit Claude Code, tenzij je daar zelf voor kiest, en bewaart het die data standaard 30 dagen, staat in [de documentatie over datagebruik](https://code.claude.com/docs/en/data-usage). [Zero data retention](/compliance/zero-data-retention) voor Claude Code bestaat alleen op Enterprise, via het accountteam van Anthropic.

## Wat kost Claude Code via de API in de Claude Console?

Met een account in de Claude Console betaal je per token, tegen de gewone tarieven van de Claude API. Bij de eerste login wordt automatisch een workspace "Claude Code" aangemaakt. Daar zie je de kosten en zet je een limiet.

In [de kostendocumentatie van Claude Code](https://code.claude.com/docs/en/costs) staat dit gemiddelde: "Across enterprise deployments, the average cost is around $13 per developer per active day and $150-250 per developer per month, with costs remaining below $30 per active day for 90% of users." Omgerekend is dat €11,64 per actieve dag en €134,26 tot €223,77 per maand. Het is een gemiddelde over klanten van Anthropic, geen offerte. Per ontwikkelaar verschilt het sterk, door model, codebase en werkwijze. Bij elk verzoek gaat het hele gesprek mee, dus een sessie die de hele dag openstaat kost per vraag steeds meer. Anthropic raadt aan met een kleine pilotgroep je eigen gemiddelde te meten.

Tabel: Prijzen van de Claude API per miljoen tokens, stand 2 november 2026.

| Model | Input | Output |
|---|---|---|
| Sonnet 5.5 | $2 | $10 |
| Opus 5.5 | $4 | $20 |
| Haiku 5.5, prompt tot 100.000 tokens | $0,10 | $0,50 |
| Haiku 5.5, prompt boven 100.000 tokens | $0,50 | $2,50 |
| Fable 5.1 | $10 | $50 |

De tarieven staan in [de prijzen van het Claude Platform](https://platform.claude.com/docs/en/about-claude/pricing). Leest een verzoek tekst uit de cache, dan kost dat op Opus 5.5 en Sonnet 5.5 0,05 keer de inputprijs. Met eigen aantallen kun je [zelf uitrekenen met de Claude API kosten calculator](/tools/claude-api-kosten-calculator).

Tabel: Rekenvoorbeeld Claude Code-kosten voor 5 ontwikkelaars per maand, stand 2 november 2026, ECB-koers 30 oktober 2026.

| Opzet | Berekening | USD per maand | EUR per maand |
|---|---|---|---|
| 5 Team-standaard, jaarbetaling | 5 x $20 | $100 | €89,51 |
| 5 Team-standaard, maandbetaling | 5 x $25 | $125 | €111,89 |
| 3 standaard en 2 premium, jaarbetaling | 3 x $20 + 2 x $100 | $260 | €232,72 |
| 5 Team-premium, jaarbetaling | 5 x $100 | $500 | €447,55 |
| 5 via de Console, gemiddelde van Anthropic | 5 x $150 tot $250 | $750 tot $1.250 | €671,32 tot €1.118,87 |
| Ter vergelijking: Enterprise-minimum | 20 x $20, plus verbruik | $400 plus verbruik | €358,04 plus verbruik |

Prijzen exclusief belasting, 1 euro is 1,1172 dollar.

Zo reken je het voor je eigen team uit:

1. Tel je ontwikkelaars en schat per persoon hoeveel dagen per maand ze Claude Code echt gebruiken.
2. Seats: tel de standaard seats keer $20 (jaar) of $25 (maand), plus de premium seats keer $100 of $125.
3. API: ontwikkelaars keer actieve dagen keer de kosten per dag. Neem $13 als begin en meet daarna je eigen gemiddelde met `/usage` of in de Console.
4. Enterprise: aantal seats (minimaal 20) keer $20, plus het verbruik uit stap 3.

Een rekensom met dat gemiddelde: bij $13 per actieve dag kost een ontwikkelaar via de API na 2 dagen ongeveer een standaard seat bij maandbetaling ($25), na ongeveer 10 dagen een premium seat ($125). Een seat heeft wel een gebruikslimiet, en de API niet. Je eigen team kan erboven of eronder uitkomen.

Team krijgt elke maand ook API-credits: $20 per standaard seat en $100 per premium seat, samen hooguit $500, volgens [het helpartikel over API-credits](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans). ## Abonnement of API: welke route past bij jouw ontwikkelaars?

Loop per ontwikkelaar deze vier vragen langs:

1. **Werkt de ontwikkelaar met code of data van klanten?** Kies dan Team, Enterprise of de Console. Daar traint Anthropic niet op je code en prompts. Op Pro, Max en Ultra beslist elke gebruiker dat zelf.
2. **Gebruikt de ontwikkelaar Claude Code de meeste werkdagen?** Dan is een seat meestal goedkoper, zie de rekensom hierboven. Begin op standaard en stap over naar premium als de limiet steeds in de weg zit.
3. **Gebruikt de ontwikkelaar het af en toe, of wil je per persoon zien wat het kost?** Dan past de Console, met een limiet op de workspace en een overzicht per lid.
4. **Heb je 20 of meer gebruikers en wil je geen limiet per seat?** Dan past Enterprise.

Je kunt routes mengen: volgens de kostendocumentatie betaal je per ontwikkelaar via de login die die persoon gebruikt. Hulp bij het inrichten van seats en limieten zit in de rollout [Claude in 30 dagen](/claude-in-30-dagen).

## Wat kost Claude Code als het automatisch draait?

Claude Code kan ook zonder scherm draaien met `claude -p`: in scripts, op een server of bij automatische tests bij elke codewijziging (CI). Welke rekening je dan krijgt, hangt af van de login. Volgens [de documentatie over inloggen](https://code.claude.com/docs/en/authentication) gaat een `ANTHROPIC_API_KEY` in de omgeving voor op je abonnement. In een gewone sessie vraagt Claude Code één keer of je de key wilt gebruiken. Zonder scherm gebruikt het de key altijd. Staat er per ongeluk een key klaar, dan betaal je API-tarief terwijl je een abonnement hebt.

Wil je op een server met je abonnement werken, dan maak je met `claude setup-token` een token dat een jaar geldig is, voor Pro, Max, Ultra, Team en Enterprise. Volgens het artikel over API-credits vallen `claude -p` en de Claude Agent SDK wel onder de credits van Max, Ultra en Team, met een API-key uit de gekoppelde Console-organisatie. De GitHub Action van Claude Code valt er niet onder. Het helpartikel over Claude Code op Team en Enterprise zegt alleen dat de credits niet in Claude Code gelden. Vraag het na bij Anthropic voordat je erop rekent.

Leg daarom vooraf vast:

1. Kies een token van je abonnement of een API-key uit de Console.
2. Controleer daarna met `/status` welke login er echt actief is.
3. Zet bij een API-key een limiet op de workspace in de Console.

Wij laten Claude Code voor deze site ook automatisch werk doen, op een Mac die als server draait. Op 23 oktober 2026 stopten vijf van die runs direct met de melding "Not logged in". Waarom precies, staat niet in onze werklogboeken. Een losse test via SSH gaf dezelfde melding: de login stond in de sleutelhanger van macOS, en die was via SSH niet bereikbaar. Op 27 oktober liepen op dezelfde machine 16 runs zonder die fout. [De hulppagina over inlogproblemen](https://code.claude.com/docs/en/troubleshoot-install) beschrijft dit geval op macOS en hoe je het herstelt. Bepaal dus vooraf hoe een onbewaakte run inlogt, want daar hangt ook van af wie de rekening betaalt.

## Hoe houd je de Claude Code kosten in de hand?

- **Meten.** Op een abonnement laat `/usage` zien waar je gebruik heen gaat. Met een API-account schat hetzelfde commando de kosten van je sessie. Team en Enterprise hebben volgens de kostendocumentatie een uitgavenoverzicht per gebruiker en per model, met alleen wat er met usage credits boven de seat is uitgegeven.
- **Begrenzen.** Op Team is de seat de grens, met usage credits zet je een limiet per organisatie en per lid. In de Console zet je een limiet op de workspace "Claude Code".
- **In golven uitrollen.** [De handleiding van Anthropic over verbruik op Enterprise](https://support.claude.com/en/articles/14782391-claude-enterprise-consumption-guide) raadt aan Claude Code en Cowork in golven uit te rollen, te beginnen bij de teams die er het meest aan hebben. Begin met voorzichtige limieten per groep en per gebruiker.
- **Het juiste model.** Volgens de kostendocumentatie doet Sonnet het meeste programmeerwerk goed voor minder geld. Opus kost per beurt een paar keer zoveel, staat in [het helpartikel over modellen in Claude Code](https://support.claude.com/en/articles/14552983-models-usage-and-limits-in-claude-code). Meer daarover lees je bij [welk Claude-model je kiest](/nieuws/welk-claude-model-mkb).
- **Context klein houden.** Start met `/clear` een nieuwe sessie als je aan iets anders begint. Houd CLAUDE.md, dat bij elke sessie meegaat, onder de 200 regels. Agent teams, waarin meerdere sessies samenwerken, gebruiken volgens Anthropic in plan mode ongeveer 7 keer zoveel tokens als een gewone sessie.

Ons team bouwde eerder bij een groeiend Nederlands softwarebedrijf met 36+ repositories in 3 weken een gedeelde basisconfiguratie ([case: van 36 losse repos naar één workspace](/cases/devops-monorepo)). Daarin staat ook welke taak naar welk model gaat: zwaar denkwerk naar een sterk model, uitvoering naar een snel model. De case noemt geen bedragen.
