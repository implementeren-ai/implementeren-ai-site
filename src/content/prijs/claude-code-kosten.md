De Claude Code kosten voor een bedrijf hangen af van één keuze: betaal je per ontwikkelaar een vaste seat, of betaal je per token wat er verbruikt wordt? Een los abonnement voor alleen Claude Code bestaat niet. Volgens [de productpagina van Claude Code](https://claude.com/product/claude-code) krijg je het bij een betaald Claude-plan, of je logt in met een account in de Claude Console en betaalt per token.

Hieronder staan alle routes naast elkaar, met een rekenvoorbeeld voor 5 ontwikkelaars en de instellingen waarmee je de rekening begrenst. Alles is op 2 november 2026 gecontroleerd bij de bronnen onderaan. Wat Claude Code is, lees je in [Claude Code voor bedrijven](/gids/claude-code-voor-bedrijven).

## Wat kost Claude Code per ontwikkelaar?

Tabel: Wat Claude Code per ontwikkelaar per maand kost, per route, stand 2 november 2026.

| Route | Prijs per ontwikkelaar per maand (USD, excl. belasting) | Hoeveel gebruik | Voorwaarden | Past bij |
|---|---|---|---|---|
| Pro | $20, of $17 bij jaarbetaling | basis, gedeeld met chat | consument | één persoon die het probeert |
| Max | $100, alleen maandelijks | 5 keer Pro, per 5 uur en per week | consument | één zware gebruiker |
| Ultra (voorheen Max 20x) | $200, alleen maandelijks | 10 keer Pro per week, geen 5-uurslimiet voor een geverifieerd account | consument | één zeer zware gebruiker |
| Team, standaard seat | $25, of $20 bij jaarbetaling | 1,25 keer Pro per sessie | zakelijk | ontwikkelaar die af en toe werkt; 2 tot 150 seats |
| Team, premium seat | $125, of $100 bij jaarbetaling | 6,25 keer Pro per sessie | zakelijk | ontwikkelaar die er de hele dag in werkt |
| Enterprise | $20 per seat (jaarlijks, minimaal 20) plus al het verbruik tegen API-tarief | geen limiet per seat, je zet zelf limieten op de uitgaven | zakelijk | 20 of meer gebruikers |
| Claude Console (API) | per token; gemiddeld $150 tot $250 volgens Anthropic | geen seat, wel een limiet per workspace | zakelijk | wisselend gebruik, automatisering, kosten per persoon zien |

De bedragen komen van [de prijspagina van Claude](https://claude.com/pricing) en zijn in dollar, exclusief belasting. Omgerekend met de ECB-koers van 30 oktober 2026 (1 euro is 1,1172 dollar) kost een standaard seat op Team €17,90 per maand bij jaarbetaling en €22,38 bij maandbetaling. Een premium seat kost dan €89,51 of €111,89. Hoe dat op je factuur uitpakt, lees je bij [btw en wisselkoers bij Claude](/prijs).

Voor een bedrijf zijn Team, Enterprise en de Console de zakelijke routes. Pro, Max en Ultra zijn abonnementen voor één persoon, onder de consumentenvoorwaarden van Anthropic. Het gratis plan heeft geen Claude Code. Op Pro, Max en Ultra deel je de limiet met de gewone Claude, staat in [het helpartikel over Claude Code op Pro, Max en Ultra](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-max-or-ultra-plan). Volgens [de kostendocumentatie van Claude Code](https://code.claude.com/docs/en/costs) deelt ook een Team-seat die ruimte met de chat en Cowork.

## Wat krijg je op Claude Team en Enterprise voor Claude Code?

Volgens [het helpartikel over Claude Code op Team en Enterprise](https://support.claude.com/en/articles/11845131-use-claude-code-with-your-team-or-enterprise-plan) zit Claude Code in elke Team-seat. Anthropic bevestigde dat ook bij de prijsverlaging van Team op 28 januari 2026.

Het verschil tussen de seats zit in de ruimte. [Het helpartikel over het Team-plan](https://support.claude.com/en/articles/9266767-what-is-the-team-plan) noemt voor een standaard seat 1,25 keer de ruimte van Pro per sessie, en voor een premium seat 6,25 keer. Je mag beide soorten seats in één team mengen. Ons advies: zet iedereen eerst op standaard en geef alleen wie de hele dag in Claude Code werkt een premium seat. De afweging tussen de plannen staat in [Claude Pro, Team of Enterprise](/prijs/pro-vs-team-vs-enterprise).

Loopt een ontwikkelaar tegen de limiet van de seat aan, dan kan een beheerder [usage credits voor Team aanzetten](https://support.claude.com/en/articles/12005970-manage-usage-credits-for-team-and-seat-based-enterprise-plans). Dat gebruik betaal je tegen API-tarief, met een maandlimiet voor de hele organisatie en per lid. Lees vooraf [hoe de gebruikslimieten werken](/prijs/credits-en-limieten).

Claude Enterprise rekent anders. Volgens [het helpartikel over het Enterprise-plan](https://support.claude.com/en/articles/9797531-what-is-the-enterprise-plan) geeft de seat toegang tot Claude, Claude Code en Cowork, en betaal je al het gebruik apart tegen API-tarief. Er is geen limiet per seat. Beheerders zetten limieten voor de hele organisatie en per gebruiker. Online koop je minimaal 20 seats, via sales minimaal 50.

Naast de prijs telt wat er met je code gebeurt. Op Team, Enterprise en de API traint Anthropic geen modellen op code of prompts uit Claude Code, tenzij je daar zelf voor kiest, staat in [de documentatie over datagebruik](https://code.claude.com/docs/en/data-usage). Die data bewaart Anthropic standaard 30 dagen. [Zero data retention](/compliance/zero-data-retention) voor Claude Code bestaat alleen op Enterprise, via het accountteam van Anthropic.

## Wat kost Claude Code via de API in de Claude Console?

Volgens de productpagina van Claude Code betaal je met een account in de Claude Console per token, tegen de gewone tarieven van de Claude API, zonder seat. De eerste keer dat iemand Claude Code met een Console-account koppelt, wordt er automatisch een workspace "Claude Code" aangemaakt. Daar zie je de kosten en zet je een limiet.

Hoeveel dat per ontwikkelaar is, verschilt sterk. In [de kostendocumentatie van Claude Code](https://code.claude.com/docs/en/costs) staat dit gemiddelde: "Across enterprise deployments, the average cost is around $13 per developer per active day and $150-250 per developer per month, with costs remaining below $30 per active day for 90% of users." Omgerekend is dat €11,64 per actieve dag en €134,26 tot €223,77 per maand. Het is een gemiddelde over klanten van Anthropic, geen offerte. Anthropic raadt aan om met een kleine pilotgroep te beginnen en eerst je eigen gemiddelde te meten.

De kosten hangen af van het model, de grootte van de codebase en de manier van werken, bijvoorbeeld met meerdere sessies tegelijk. Bij elk verzoek gaat het hele gesprek mee. Een sessie die de hele dag openstaat, kost daardoor per vraag steeds meer.

Tabel: Prijzen van de Claude API per miljoen tokens, stand 2 november 2026.

| Model | Input | Output |
|---|---|---|
| Sonnet 5.5 | $2 | $10 |
| Opus 5.5 | $4 | $20 |
| Haiku 5.5 | $0,10 (tot 100.000 tokens per prompt) | $0,50 |
| Fable 5.1 | $10 | $50 |

De tarieven staan in [de prijzen van het Claude Platform](https://platform.claude.com/docs/en/about-claude/pricing). Leest een verzoek tekst uit de cache, dan kost dat op Opus 5.5 en Sonnet 5.5 0,05 keer de inputprijs. Wil je met je eigen aantallen rekenen, dan kun je dat [zelf uitrekenen met de Claude API kosten calculator](/tools/claude-api-kosten-calculator).

## Rekenvoorbeeld: wat kost Claude Code voor een team van 5 ontwikkelaars?

Tabel: Rekenvoorbeeld Claude Code-kosten voor 5 ontwikkelaars per maand, stand 2 november 2026, ECB-koers 30 oktober 2026.

| Opzet | Berekening | USD per maand | EUR per maand |
|---|---|---|---|
| 5 Team-standaard, jaarbetaling | 5 x $20 | $100 | €89,51 |
| 5 Team-standaard, maandbetaling | 5 x $25 | $125 | €111,89 |
| 3 standaard en 2 premium, jaarbetaling | 3 x $20 + 2 x $100 | $260 | €232,72 |
| 5 Team-premium, jaarbetaling | 5 x $100 | $500 | €447,55 |
| 5 via de Console, gemiddelde van Anthropic | 5 x $150 tot $250 | $750 tot $1.250 | €671,32 tot €1.118,87 |
| Ter vergelijking: Enterprise-minimum | 20 x $20, plus verbruik | $400 plus verbruik | €358,04 plus verbruik |

Prijzen exclusief belasting, 1 euro is 1,1172 dollar. Enterprise staat er alleen ter vergelijking: met 5 ontwikkelaars haal je het minimum van 20 seats niet.

Zo reken je het voor je eigen team uit:

1. Tel je ontwikkelaars en schat per persoon hoeveel dagen per maand ze Claude Code echt gebruiken.
2. Seats: tel de standaard seats keer $20 (jaar) of $25 (maand), plus de premium seats keer $100 of $125.
3. API: ontwikkelaars keer actieve dagen keer de kosten per dag. Neem $13 als begin en meet daarna je eigen gemiddelde met `/usage` of in de Console.
4. Enterprise: aantal seats (minimaal 20) keer $20, plus het verbruik uit stap 3.

Een rekensom met dat gemiddelde: bij $13 per actieve dag kost een ontwikkelaar via de API na 2 actieve dagen ongeveer evenveel als een standaard seat bij maandbetaling ($25). Na ongeveer 10 dagen is dat evenveel als een premium seat ($125). Een seat heeft wel een gebruikslimiet, en de API niet. Het blijft een rekensom met een gemiddelde, geen voorspelling.

Team krijgt elke maand ook API-credits: $20 per standaard seat en $100 per premium seat, samen hooguit $500, volgens [het helpartikel over API-credits](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans). ## Abonnement of API: welke route past bij jouw ontwikkelaars?

Loop per ontwikkelaar deze vier vragen langs:

1. **Werkt de ontwikkelaar met code of data van klanten?** Kies dan een zakelijke route: Team, Enterprise of de Console. Daar traint Anthropic niet op je code en prompts. Op Pro, Max en Ultra beslist elke gebruiker dat zelf met een instelling.
2. **Gebruikt de ontwikkelaar Claude Code de meeste werkdagen?** Dan is een seat meestal goedkoper dan betalen per token, zie de rekensom hierboven. Begin op standaard en stap over naar premium als de limiet steeds in de weg zit.
3. **Gebruikt de ontwikkelaar het af en toe, of wil je per persoon zien wat het kost?** Dan past de Console. Je betaalt per token, met een limiet op de workspace en een overzicht per lid.
4. **Heb je 20 of meer gebruikers en wil je geen limiet per seat?** Dan past Enterprise: $20 per seat plus verbruik, met limieten per organisatie en per gebruiker.

Je kunt routes mengen: volgens de kostendocumentatie betaal je per ontwikkelaar via de login die die persoon gebruikt. Hulp bij het opzetten van de seats voor Claude Team of Enterprise zit in de rollout [Claude in 30 dagen](/claude-in-30-dagen).

## Wat kost Claude Code als het automatisch draait?

Claude Code kan ook zonder scherm draaien, in scripts, in CI of op een server, met `claude -p`. Welke rekening je dan krijgt, hangt af van de login. Volgens [de documentatie over inloggen](https://code.claude.com/docs/en/authentication) gaat een `ANTHROPIC_API_KEY` in de omgeving voor op je abonnement, en zonder scherm wordt die key altijd gebruikt. Staat er per ongeluk een key klaar, dan betaal je API-tarief terwijl je een abonnement hebt.

Wil je op een server met je abonnement werken, dan maak je met `claude setup-token` een token dat een jaar geldig is. Dat werkt met Pro, Max, Ultra, Team en Enterprise. Volgens het artikel over API-credits vallen `claude -p` en de Claude Agent SDK wel onder de credits van Max, Ultra en Team, als je ze zelf draait met een API-key uit de gekoppelde Console-organisatie. De GitHub Action van Claude Code valt er niet onder.

Leg daarom vooraf vast:

1. Kies een token van je abonnement of een API-key uit de Console.
2. Controleer daarna met `/status` welke login er echt actief is.
3. Zet bij een API-key een limiet op de workspace in de Console.

Dit kwamen we zelf tegen. Wij laten Claude Code voor deze site ook automatisch werk doen, op een Mac die als server draait. Op 23 oktober 2026 stopten vijf van die runs direct met de melding "Not logged in". Waarom die vijf geen login hadden, staat niet in onze logboeken. Een losse test via SSH gaf dezelfde melding: de login stond in de sleutelhanger van macOS, en die was via SSH niet bereikbaar. Op 27 oktober liepen op dezelfde machine 16 runs zonder die fout. Dit komt uit onze eigen werklogboeken. [De hulppagina over inlogproblemen](https://code.claude.com/docs/en/troubleshoot-install) beschrijft dit geval op macOS en hoe je het herstelt. Bepaal dus vooraf hoe een onbewaakte run inlogt, want daar hangt ook van af wie de rekening betaalt.

## Hoe houd je de Claude Code kosten in de hand?

- **Meten.** Op een abonnement laat `/usage` zien waar je gebruik heen gaat, met tips. Met een API-account schat hetzelfde commando de kosten van je sessie. Volgens de kostendocumentatie hebben Team en Enterprise een uitgavenoverzicht per gebruiker en per model, met CSV-export. Daarin staat alleen wat er met usage credits boven de seat is uitgegeven.
- **Begrenzen.** Op Team is de seat zelf de grens, en met usage credits stel je een limiet in voor de organisatie en per lid. In de Console zet je een limiet op de workspace "Claude Code".
- **In golven uitrollen.** [De handleiding van Anthropic over verbruik op Enterprise](https://support.claude.com/en/articles/14782391-claude-enterprise-consumption-guide) raadt aan Claude Code en Cowork in golven uit te rollen, te beginnen bij de teams die er het meest aan hebben. Begin voorzichtig met limieten per groep en per gebruiker, want een limiet verhogen is makkelijker dan achteraf een overschrijding bespreken.
- **Het juiste model.** Volgens de kostendocumentatie doet Sonnet het meeste programmeerwerk goed voor minder geld dan Opus. [Het helpartikel over modellen in Claude Code](https://support.claude.com/en/articles/14552983-models-usage-and-limits-in-claude-code) zegt dat Opus per beurt een paar keer zoveel kost als Sonnet. Meer daarover lees je bij [welk Claude-model je kiest](/nieuws/welk-claude-model-mkb).
- **Context klein houden.** Start met `/clear` een nieuwe sessie als je aan iets anders begint. Het bestand CLAUDE.md gaat bij elke sessie mee: houd het volgens Anthropic onder de 200 regels. Agent teams, waarin meerdere sessies samenwerken, gebruiken in plan mode ongeveer 7 keer zoveel tokens als een gewone sessie.

Ons team bouwde eerder bij een groeiend Nederlands softwarebedrijf met 36+ repositories in 3 weken een gedeelde basisconfiguratie ([case: van 36 losse repos naar één workspace](/cases/devops-monorepo)). Daarin staat ook welke taak naar welk model gaat: zwaar denkwerk naar een sterk model, uitvoering naar een snel model. De case meet de tijd voor een nieuw project, van 30+ naar 5 minuten, en noemt geen bedragen.
